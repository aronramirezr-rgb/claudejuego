# Reino Sombrío

Un roguelike de supervivencia por oleadas, de fantasía medieval, en pixel art. Se juega en el navegador: no hay que instalar nada.

## Jugar

- **PC:** https://aronramirezr-rgb.github.io/claudejuego/
- **Celular (en horizontal):** https://aronramirezr-rgb.github.io/claudejuego/movil.html

También puedes descargar el repositorio y abrir `index.html` con doble clic.

## Controles

| | PC | Celular |
|---|---|---|
| Moverse | WASD o flechas | Palanca (mitad izquierda de la pantalla) |
| Pausa | Esc o P | Botón ❚❚ |
| Elegir mejora | Teclas 1-4 o clic | Tocar la tarjeta |

Las armas atacan solas: tú te mueves, esquivas y eliges mejoras.

## Qué tiene

- 3 héroes: Caballero, Maga y Arquero. Cada uno tiene 20 mejoras posibles, 4 de ellas exclusivas.
- 4 zonas con su jefe final (Bosque, Cementerio, Cripta y Castillo) y El Abismo, una zona infinita.
- Cofres, salas secretas tras muros agrietados, reliquias de los jefes y evoluciones de armas.
- Tienda de mejoras permanentes con el oro de cada partida.
- Música y efectos generados por código, en español e inglés.

## Archivos

- `index.html`: versión de PC. `movil.html`: versión para celular.
- `js/data.js`: casi todo el equilibrio (vida, daño, enemigos de cada zona, precios).
- `tools/serve.ps1`: servidor local opcional para probar el juego en el PC.
